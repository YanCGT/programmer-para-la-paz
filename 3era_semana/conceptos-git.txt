Repositorio:
Un repositorio es el lugar donde se almacenan los archivos y el historial de cambios de un proyecto. 
Permite organizar el trabajo y colaborar con otros desarrolladores de manera ordenada.

Commit:
Un commit es un registro de los cambios realizados en un proyecto. 
Cada commit guarda una versión específica del trabajo con un mensaje descriptivo.

Push:
El comando push se utiliza para enviar los cambios del repositorio local hacia un repositorio remoto como GitHub.
Esto permite compartir y respaldar el proyecto en línea.
