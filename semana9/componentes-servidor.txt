Sistema operativo:
Es el software principal que administra los recursos del computador y permite ejecutar programas y servicios. También controla el acceso al hardware.

Node.js:
Es un entorno de ejecución que permite correr aplicaciones JavaScript fuera del navegador. Se utiliza para desarrollar servidores y aplicaciones web.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y las respuestas que recibirán los usuarios.

Puerto:
Es un punto de comunicación por el cual el servidor recibe solicitudes. En este ejercicio se utiliza el puerto 3000.

Logs:
Son registros que almacenan eventos y actividades del sistema o la aplicación. Ayudan a monitorear el funcionamiento y detectar errores.
